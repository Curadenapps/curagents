# Onboarding path

Train the trainer: each level is trained before it trains the level below. HQ
(Sean) trains levels 1–2 in every market; the market trains levels 3–6 with HQ
watching the first time.

## The six levels

| # | Level | Who | Trained by | Modules | Done when |
|---|-------|-----|-----------|---------|-----------|
| 1 | Market owner | Local lead (Curaden subsidiary or distributor) | Sean | M0, M7, M8, M9 | Can explain the loop, the market's gates and KPIs, and knows how to ask HQ |
| 2 | Admin Console super user | 1–2 per market, often the market owner's right hand or an OHC lead | Sean, with Phinamic for access | M0, M1, M2, M8, then certification | Certified (below) and has onboarded one practice with HQ watching |
| 3 | Practice owner | Dentist or practice manager who signs | Super user or market team | M2, M6 (once the loop is live there) | Agreement signed, practice approved, staff named |
| 4 | Hygienist / PA | Runs BOB in the chair | Super user, in the practice | M3, M4 | First 5 real assessments done (the "Activated" stage) |
| 5 | Front desk | Consent, handover, recall | Super user or hygienist | M4 | Can run consent and handover without help |
| 6 | Patient | Gets the plan | The practice | M5 (patient materials, not a course) | Opens the plan (patient ladder stage 1) |

Field teams (OHCs in the UAE, sales reps elsewhere) take M0, M2, M3 and M9 so they
can demo and recruit; they get Admin Console access only if they're also super users.

## Admin Console super user

**What they do:** approve practices for their market; set up practices and staff;
switch features on per practice (feature opt-in); check practice-side KPIs; first-line
support (answer, or send to HQ through the App Request form); onboard and train practices.

**Before access is requested**
- Named by the market owner, agreed by Sean.
- Market's Gate 0 done for that market (US: also no real-patient approvals before Gate 1).
- Console known: one per country or shared multi-tenant is still open with Phinamic
  (Asana `1219987603562447`). Legacy UAE console: admin-ae.curaprox.app.

Never put a password in the request or the tracker. Access is removed the same way
(Admin access `Removed`) when someone leaves.

**Certification checklist** (Sean or the HQ trainer ticks it during a live session)
- [ ] Approves a test practice and explains what they checked before approving
      (US: BAA signed; CH: processing agreement; JP: entrustment agreement; UAE: clinic agreement;
      IT: processing agreement)
- [ ] Adds staff to a practice and switches a feature on and off
- [ ] Runs a BOB assessment end to end on the demo practice and sends the plan
- [ ] Explains consent to a patient in the market's language, using the market's consent text
- [ ] Finds a practice's numbers on the KPI ladder
- [ ] Answers three common support questions and knows when to send one to HQ
- [ ] Knows what not to say: no diagnosis, no "prescription", no efficacy claims beyond approved wording
- [ ] Onboards one real practice with HQ watching

Stage moves: `Named` → `Invited` (Sean sent the invite) → `Access granted` → `Training`
→ `Certified` (checklist done) → `Training others` (first practice onboarded on their own).

## Practice onboarding (what the super user runs)

1. Sign-up and approval, with the market's agreement in place.
2. 30-minute kick-off with the owner (M2): the loop, the commission (where live), consent.
3. In-practice session with the hygienist (M3, M4): first real assessment together on day one.
4. Day 7 check: assessments done? If none, a call (not an email).
5. Day 30: activated (5 assessments) or a plan to get there.
6. Day 90: habit (10 a month) and loop running where Shopify is live.

## Timing against the gates

| When | What |
|------|------|
| Gate 0 | Market owner named and trained (level 1); super user named |
| T–8 weeks before Gate 1 | Access requested; super user training starts |
| Before Gate 1 closes | Super user certified; first-wave practices picked and booked |
| Gate 1 done | First practices with real patients, super user onboarding with HQ watching |
| Gate 2 done | M6 (commission and codes) for live practices |
